== Introduction

This document contains diagrams and visual aids to help understand the Chronicle Wire library. It complements the text-based documentation by providing visual representations of key concepts, processes, and components.

== Architectural Overview

=== Layered Architecture

[mermaid]
----
graph TD
    A[Application Code] -->|Interacts via| B[Chronicle Wire API Layer]
    B -->|Selects and dispatches to| C[Wire Format Implementation Layer]
    C -->|Operates on / Uses| D[Chronicle Bytes Layer]
    D -->|Reads from / Writes to| E[Underlying I/O or Storage Layer]

    %% Optional Styling for better visual separation

    class A appLayer;

    class D bytesLayer;
    class E ioLayer;
----

== Serialization and Deserialization Process

[mermaid]
----
graph TD
    subgraph "Serialisation Process"
        A[Java Object] -->|"implements Marshallable"| B[Marshallable Object]
        B -->|"writeMarshallable()"| C[Wire]
        C -->|"WireType (YAML, JSON, Binary)"| D[Bytes]
        D -->|"Store/Transmit"| E[Persistence/Network]
    end
    
    subgraph "Deserialisation Process"
        F[Persistence/Network] -->|"Read"| G[Bytes]
        G -->|"WireType (same as serialisation)"| H[Wire]
        H -->|"readMarshallable()"| I[Marshallable Object]
        I -->|"Field Population"| J[Java Object]
    end
----

== Schema Evolution

[mermaid]
----
graph TD
    subgraph "Schema Evolution Overview"
        A[Schema Changes] --> B{Type of Change}
        B -->|Add Field| C[Forward Compatible]
        B -->|Remove Field| D[Backward Compatible]
        B -->|Rename Field| E[Needs Special Handling]
        B -->|Change Type| F[Complex - May Need Custom Logic]
        
        C -->|"Older Reader"| G[Ignores Unknown Fields]
        D -->|"Newer Reader"| H[Uses Default Values]
        E -->|"@FieldNumber or Rename Map"| I[Maps Old Name to New]
        F -->|"Custom readMarshallable"| J[Custom Conversion Logic]
        
        K[Wire Format] --> L{Compatibility Level}
        L -->|"YAML/JSON/BINARY_LIGHT"| M[Good Schema Evolution]
        L -->|"FIELDLESS_BINARY"| N[Limited/No Evolution]
    end
----
